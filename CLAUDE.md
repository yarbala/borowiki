# borowiki

Личное некоммерческое приложение: карта, показывающая **точные места, где за последние 7 дней гроза прошла над лесом, и время грозы** (гипотеза пользователя: после гроз идут грибы). Регион: Вроцлав + 200 км. Общение с пользователем — на русском.

## Главный принцип

Максимально простой, но сразу рабочий вариант. Приложение для одного человека: без аккаунтов, уведомлений, ML, прогнозных индексов и длинной истории. Любое усложнение — только по явной просьбе.

Пользователь уже отверг: крупные области/зоны по погодной сетке (нужны реальные следы гроз) и хранение истории (нужны только последние 7 дней на момент обновления).

## Данные (только открытые, ключи не нужны)

- Грозы: EUMETView WMS, слой `mtg_fd:li_afa` (MTG Lightning Imager, шаг 5 мин). Диапазон `time=a/b` кадры не объединяет — запрос на каждый шаг, с кэшем.
- Дополнительно: живой сборщик Blitzortung (точки 1–3 км; только пока Mac включён; допустимо, т.к. проект некоммерческий).
- Леса и подложка: векторные тайлы OpenFreeMap (данные OSM), стиль Liberty; лес = слой `landcover`, класс `wood`.
  Карта на MapLibre GL. В тайлах лес есть с z8; для обзора (z≤9) слой собирается заранее в `public/data/forests.json` (`npm run forests`).
- Осадки в карточке: Open-Meteo, точечный запрос из браузера.
- Названия мест: Overpass (города в радиусе, кэш).

Реальная точность положения грозы — несколько км (предел прибора). Не обещать большего.

## Интерфейс

Один экран: карта, контур леса под следом грозы закрашен по оценке (не круг — сам лес) (красный — свежая, жёлтый — 7 дней назад; зелёный не использовать). Сверху фильтр по дням. Нажатие на лес → карточка: дата и время грозы, давность, интенсивность, осадки, «Маршрут», «Нашёл/Пусто». Снизу список гроз над лесом рядом с домом. Настройки: дом и радиус. Строка статуса с временем обновления. Mobile-first. Внешний вид — по макету Claude Design от пользователя.

## Стек

Node 20+ без единой зависимости (`node_modules` не нужен) + статическая страница с Leaflet 1.9.4 c unpkg.
Свои декодеры PNG (`lib/png.mjs`) и векторных тайлов MVT (`lib/mvt.mjs`) — чтобы не тянуть npm-пакеты.

```
server.mjs            статика + POST /api/finds + автообновление раз в час
scripts/update.mjs    весь конвейер: молнии → грозы над лесом → погода → public/data/spots.json
lib/config.mjs        регион, пороги модели — единственное место с настройками
lib/lightning.mjs     кадры WMS + кэш в data/frames/
lib/storms.mjs        кадры → проходы грозы над ячейками сетки (со временем)
lib/forest.mjs        леса, пункты, охраняемые территории из тайлов + кэш в data/tiles/
lib/spots.mjs         проходы ∩ лес → пятна
lib/weather.mjs       Open-Meteo + оценка готовности 0–100
scripts/build-forests.mjs  все леса региона для обзорного масштаба (разовый запуск)
public/               index.html, style.css, app.js — интерфейс по макету
```

Команды:

```
npm start             сервер на http://localhost:8080 (и по Wi-Fi с телефона)
npm run update        пересобрать данные за последние 7 суток
npm run update:demo   собрать демо-неделю с грозами (когда за реальную неделю их не было)
npm run forests       пересобрать обзорный слой лесов (нужно один раз)
```

Первый запуск качает ~2000 кадров молний (около 7 минут) и векторные тайлы; дальше только свежие кадры.
