# borowiki

Личное некоммерческое приложение: карта, показывающая **точные места, где за последние 7 дней гроза прошла над лесом, и время грозы** (гипотеза пользователя: после гроз идут грибы). Регион: Вроцлав + 200 км (меняется командой `npm run region`, хранится в `data/region.json`). Общение с пользователем — на русском.

## Зачем это пользователю

Он проверяет гипотезу: **разряд молнии провоцирует грибницу дать боровики** (услышал в научно-популярном фильме, потом подтверждение от человека, которого дед возил собирать грибы после гроз). Его правило: приехать **через 2–4 дня** после грозы, пока боровики не выросли и их не собрали. Цель — не набрать грибов, а найти их и проверить теорию.

## Главный принцип

Приложение показывает **только измеренное**: где молнии пришлись на лес и когда. Никаких прогнозов урожая, оценок и «когда идти» — решение за человеком.

Пользователь уже отверг: крупные области по погодной сетке; хранение истории; **и мою модель готовности (оценка 0–100, горизонты «+3/+7 дней», «пик ожидается»)** — её я придумал сам, она ни на чём не проверена и противоречит его правилу 2–4 дня. Не возвращать.

## Данные (только открытые, ключи не нужны)

- Грозы: EUMETView WMS, слой `mtg_fd:li_afa` (MTG Lightning Imager, шаг 5 мин). Диапазон `time=a/b` кадры не объединяет — запрос на каждый шаг, с кэшем.
- Возможное улучшение: Blitzortung (точки 1–3 км вместо нескольких км у спутника), но он даёт только живой поток.
- Леса и подложка: векторные тайлы OpenFreeMap (данные OSM), стиль Liberty; лес = слой `landcover`, класс `wood`.
  Карта на MapLibre GL. В тайлах лес есть с z8; для обзора (z≤9) слой собирается заранее в `public/data/forests.json` (`npm run forests`).
- Осадки и температура: Open-Meteo, запрос при сборке данных.
- Названия мест: слой `place` тех же тайлов; поиск дома — Nominatim.

Реальная точность положения грозы — несколько км (предел прибора). Не обещать большего.

## Интерфейс

Один экран: все леса региона зелёные; там, где молнии пришлись на лес — **яркая метка-молния** и залитый цветом контур леса. Цвет по давности грозы: 0–1 день жёлтый «рано», **2–4 дня красный «пора ехать»**, 5–7 дней серый «поздно». Нажатие → карточка: дата и время грозы, сколько дней прошло, площадь и сила разрядов, дождь в грозу и после, температура, график за месяц, «Маршрут», «Нашёл / Пусто». Снизу список мест, самые свежие сверху. Кнопка ⚡ — все разряды за 7 дней, включая поля. Настройки: дом (с поиском по названию) и радиус. Mobile-first.

Отметки «Нашёл / Пусто» — это журнал проверки гипотезы: сохраняются с координатами, датой грозы и днём приезда после неё.

## Стек

Node 20+ без единой зависимости (`node_modules` не нужен) + статическая страница с Leaflet 1.9.4 c unpkg.
Свои декодеры PNG (`lib/png.mjs`) и векторных тайлов MVT (`lib/mvt.mjs`) — чтобы не тянуть npm-пакеты.

```
server.mjs            статика + POST /api/finds + автообновление раз в час
scripts/update.mjs    весь конвейер: молнии → грозы над лесом → погода → public/data/spots.json
lib/config.mjs        регион, пороги модели — единственное место с настройками
lib/lightning.mjs     кадры WMS + кэш в data/frames/
lib/storms.mjs        кадры → проходы грозы над ячейками сетки (со временем)
lib/forest.mjs        леса, пункты, охраняемые территории из тайлов + кэш в data/tiles/
lib/spots.mjs         проходы ∩ лес → пятна
lib/weather.mjs       Open-Meteo + оценка готовности 0–100
scripts/build-forests.mjs  все леса региона для обзорного масштаба (разовый запуск)
public/               index.html, style.css, app.js — интерфейс по макету
```

Команды:

```
npm start             сервер на http://localhost:8080 (и по Wi-Fi с телефона)
npm run update        пересобрать данные за последние 7 суток
npm run update:demo   собрать демо-неделю с грозами (когда за реальную неделю их не было)
npm run forests       пересобрать обзорный слой лесов (нужно один раз)
npm run region -- Гродно       перенести всю область данных в другое место
npm run region -- "Варшава" 150  то же, с другим радиусом
```

Первый запуск качает ~2000 кадров молний (около 7 минут) и векторные тайлы; дальше только свежие кадры.
