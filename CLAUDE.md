# borowiki

Личное некоммерческое приложение: карта, показывающая **точные места, где за последние 7 дней гроза прошла над лесом, и время грозы** (гипотеза пользователя: после гроз идут грибы). Регион: Вроцлав + 200 км (меняется командой `npm run region`, хранится в `data/region.json`). Общение с пользователем — на русском.

## Зачем это пользователю

Он проверяет гипотезу: **разряд молнии провоцирует грибницу дать боровики** (услышал в научно-популярном фильме, потом подтверждение от человека, которого дед возил собирать грибы после гроз). Его правило: приехать **через 2–4 дня** после грозы, пока боровики не выросли и их не собрали. Цель — не набрать грибов, а найти их и проверить теорию.

## Главный принцип

Приложение показывает **только измеренное**: где молнии пришлись на лес и когда. Никаких прогнозов урожая, оценок и «когда идти» — решение за человеком.

Пользователь уже отверг: крупные области по погодной сетке вместо точных мест; **и мою модель готовности (оценка 0–100, горизонты «+3/+7 дней», «пик ожидается»)** — её я придумал сам, она ни на чём не проверена и противоречит его правилу 2–4 дня. Не возвращать.

Про историю он сначала сказал «не нужна» (речь шла о накоплении архива вместо показа последней недели), а позже попросил именно режим истории — выбрать дату и увидеть состояние на неё, чтобы сверить с памятью о прошлых находках. Поэтому режим истории есть, а «копим всё подряд» — нет.

## Данные (только открытые, ключи не нужны)

- Грозы: EUMETView WMS, слой `mtg_fd:li_afa` (MTG Lightning Imager, шаг 5 мин). Диапазон `time=a/b` кадры не объединяет — запрос на каждый шаг, с кэшем.
- Возможное улучшение: Blitzortung (точки 1–3 км вместо нескольких км у спутника), но он даёт только живой поток.
- Леса и подложка: векторные тайлы OpenFreeMap (данные OSM), стиль Liberty; лес = слой `landcover`, класс `wood`.
  Карта на MapLibre GL. В тайлах лес есть с z8; для обзора (z≤9) слой собирается заранее в `public/data/forests.json` (`npm run forests`).
- Осадки и температура: Open-Meteo, запрос при сборке данных.
- Названия мест: слой `place` тех же тайлов; поиск дома — Nominatim.

Реальная точность положения грозы — несколько км (предел прибора). Не обещать большего.

## Интерфейс

Один экран: все леса региона зелёные; там, где молнии пришлись на лес — **яркая метка-молния** и залитый цветом контур леса.

**Цвет — свежесть грозы, в часах:** только что ярко-красный → неделю назад бледно-серый. Самая новая молния самая заметная и самая крупная; когда ехать, пользователь решает сам (его правило — через 2–4 дня).

Нажатие → карточка: дата и время грозы, сколько прошло («40 минут назад», «5 часов назад», «3 дня назад»), площадь и сила разрядов, дождь в грозу и после, температура, график за месяц, «Маршрут», «Нашёл / Пусто». Снизу список мест, самые свежие сверху.

Кнопки: **⚡** — все разряды за окно, включая поля; **капля** — сильные дожди над лесом (сетка 0,1°, от 10 мм за сутки, синяя шкала свежести — контроль к грозам); **календарь** — режим истории. Настройки: дом (с поиском по названию) и радиус. Mobile-first.

Вне лесов осадки не считаются вовсе — пользователь сказал, что они его не интересуют, и это экономит лимит Open-Meteo.

Отметки «Нашёл / Пусто» — это журнал проверки гипотезы: сохраняются с координатами, датой грозы и днём приезда после неё. Ключ отметки — **место и день грозы** (`51.231,14.741@2026-09-19`), а не номер пятна: номера выдаются заново при каждой сборке.

## Режим истории

Кнопка-календарь: выбор даты → сервер собирает недельное окно, заканчивающееся этой датой,
в `public/data/history/ГГГГ-ММ-ДД.json` (около 7 минут), готовые снимки показываются списком.

Глубина: молнии есть с 30 мая 2025, но окно погоды упирается в Open-Meteo — около **92 дней**,
из которых 30 уходят на график до даты снимка. Поэтому снимок собирается примерно за
**два последних месяца**; поле даты само ограничено этими границами, а сервер и сборка
отказывают с объяснением до загрузки кадров, а не после семи минут работы.
Архив ERA5 не годится: гроз он не видит вовсе.

Окно погоды отсчитывается **от даты снимка**, а не от сегодняшнего числа. Снимки хранятся
в git намеренно: пересобрать каждый стоит семи минут и части суточного лимита Open-Meteo.

## Стек

Node 20+ без единой зависимости (`node_modules` не нужен) + статическая страница с MapLibre GL 4.7.1 c unpkg.
Свои декодеры PNG (`lib/png.mjs`) и векторных тайлов MVT (`lib/mvt.mjs`) — чтобы не тянуть npm-пакеты.

```
server.mjs            статика + /api/finds + /api/history + автообновление раз в час
scripts/update.mjs    весь конвейер: молнии → грозы над лесом → погода → public/data/spots.json
lib/config.mjs        регион, пороги кластеризации, порог сильного дождя — все настройки
lib/lightning.mjs     кадры WMS + кэш в data/frames/
lib/storms.mjs        кадры → проходы грозы над ячейками сетки (со временем)
lib/forest.mjs        леса, пункты, охраняемые территории из тайлов + кэш в data/tiles/
lib/spots.mjs         проходы ∩ лес → пятна
lib/forestmask.mjs    быстрая проверка «точка в лесу» по готовому слою лесов
lib/weather.mjs       Open-Meteo: погода пятен и сетка сильных дождей над лесом
scripts/build-forests.mjs  все леса региона для обзорного масштаба (разовый запуск)
scripts/set-region.mjs     перенос всей области данных в другое место
public/               index.html, style.css, app.js — интерфейс
```

Данные пишутся через временный файл и переименование: упавшая сборка не может
испортить рабочий файл, а страница не может прочитать его наполовину записанным.

Команды:

```
npm start             сервер на http://localhost:8080 (и по Wi-Fi с телефона)
npm run update        пересобрать данные за последние 7 суток
npm run update:demo   собрать демо-неделю с грозами (когда за реальную неделю их не было)
npm run forests       пересобрать обзорный слой лесов (нужно один раз)
npm run update -- --date=2026-09-07   снимок состояния на ту дату (в public/data/history/)
npm run region -- Гродно       перенести всю область данных в другое место
npm run region -- "Варшава" 150  то же, с другим радиусом
```

Первый запуск качает ~2000 кадров молний (около 7 минут) и векторные тайлы; дальше только свежие кадры.
